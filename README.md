# Feeder V2 Firmware Releases

Public repository for **Feeder V2 STM32 firmware packages**.

- Firmware `.bin` packages and `firmware.json` are attached to GitHub Releases.
- `catalog.json` controls what Feeder Control V2 will list.
- Old Stable releases remain visible unless explicitly hidden.
- Only verified Feeder V2 packages should be published.
- Local firmware installation remains supported by Feeder Control.

Repository initialization: upload `catalog.json` and this `README.md` to the default branch.

**Important:** a SHA-256 in this repository is an integrity check, **not** a digital signature. Digital signing is planned for a later version.
